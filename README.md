# 🎒 Rastreador Pokémon GO (protótipo)

App feito por fã para acompanhar o progresso no Pokémon GO. É uma página só (`index.html`), sem cadastro e sem servidor.

- **💎 Pedra de Sinnoh, ✨ Evoluções especiais, 📚 Todas as outras:** doces, cópias e prioridades de cada evolução. Os doces são da família: anotar num card atualiza a linha inteira.
- **🗂️ Livingdex:** quais Pokémon você tem guardados, por região, com dicas do que dá pra conseguir evoluindo.
- **📖 Pokédex:** registrados, ✨ shiny, 🍀 sortudo e ⭐ 3 estrelas, com tipos e status.
- **🦋 Vivillon:** os 18 padrões regionais da medalha e os de evento.
- **🎯 Lista de caça:** marque os que você está procurando e filtre só por eles.

## Como usar

Abra o `index.html` no navegador. O progresso fica salvo **só no seu navegador**, e nada é enviado para a internet.
Use **💾 Backup** de vez em quando para baixar uma cópia, e **📂 Restaurar** para trazer os dados de volta ou passá-los para outro aparelho.
Limpar os dados do navegador apaga o progresso que não estiver num backup.
